🚀 Render 部署指南

立和设计自动化运营管理系统 · 3步完成永久部署

1注册 GitHub 账号

GitHub 是全球最大的代码托管平台，Render 从 GitHub 拉取代码进行部署。注册完全免费。

  1. 打开 github.com/signup
  2. 输入邮箱、设置密码、用户名
  3. 完成邮箱验证（去邮箱点确认链接）
  4. 选择 "Skip personalization" 跳过个性化设置
前往 GitHub 注册 →
⏱ 约2分钟完成。如果已有账号，跳过此步。

2创建 Personal Access Token (PAT)

这个 Token 让我能帮你自动创建仓库并推送代码，不需要你手动操作 Git。

  1. 登录 GitHub 后，点击右上角头像 → Settings
  2. 左侧菜单最底部 → Developer settings
  3. 选择 Personal access tokens → Tokens (classic)
  4. 点击 Generate new token (classic)
  5. Note 填写：lihe-deploy
  6. Expiration 选择 30 days
  7. 勾选 repo（第一个选项，全选仓库权限）
  8. 点击底部 Generate token
  9. 复制生成的 token（以 ghp_ 开头）
直接打开 Token 创建页 →
⚠️ Token 只显示一次，请立即复制保存。格式类似：ghp_xxxxxxxxxxxx

3告诉我你的 GitHub 用户名和 Token

把以下两个信息发给我：

用户名：你的GitHub用户名 Token：ghp_开头的token

我会自动完成：

  1. ✅ 创建 GitHub 仓库并推送全部代码
  2. ✅ 在 Render 上创建 Web Service
  3. ✅ 配置所有环境变量（飞书 API 凭证等）
  4. ✅ 启动服务并返回永久线上地址
完成后你会得到一个永久 URL，客户和员工随时可访问，无需本地电脑开机。
