部署指南：已签约自动同步

功能已在本地测试通过，按以下步骤部署到线上

✅ 本地测试已通过：将"淼淼"的跟进状态改为"已签约" → 同步接口自动在项目管理表创建了项目记录，字段映射正确，防重复也OK。

1 手动触发 Render 重新部署

代码已推送到 GitHub，但 Render 自动部署可能未开启。手动触发：

  • 打开 Render Dashboard
  • 点击你的服务 lihe-design
  • 页面右上角点击 Manual Deploy → Deploy latest commit
  • 等待 2-3 分钟，看到状态变为 Live

部署完成后，访问以下地址验证：

https://lihe-design.onrender.com/api/sync-signed?staffId=D01&password=lihe2026

如果返回 JSON（而不是 "Not found"），说明部署成功。

2 配置飞书事件订阅（实时自动同步）

配置后，当你在多维表格中把跟进状态改为"已签约"时，系统会自动在项目管理表创建记录，无需手动触发。

  • 打开 飞书开发者后台 - 事件订阅
  • 找到事件配置区域
  • 请求地址填写：
    https://lihe-design.onrender.com/api/webhook
  • 点击添加事件，搜索并订阅：多维表格记录变更 (bitable.v1.record.changed)
  • 保存后飞书会发送验证请求，如果返回成功则配置完成
⚠️ 需要先完成第1步（Render部署），飞书验证请求才能通过。

3 手动同步（备用方案）

如果你不想配置事件订阅，也可以手动触发同步：

  • 在多维表格中把需求记录的"跟进状态"改为"已签约"
  • 访问同步接口（需要员工登录）：
https://lihe-design.onrender.com/api/sync-signed?staffId=D01&password=lihe2026

系统会自动查找所有"已签约"的需求，为还没有项目记录的客户创建项目记录。
